# Анализ продаж интернет-магазина (пример проекта по аналитике данных)

Сквозной проект, какие делают джуниор- и мидл-аналитики: от «грязных» выгрузок до отчёта с рекомендациями для бизнеса.

**Бизнес-вопрос:** откуда приходит выручка, какие клиенты возвращаются и куда направить маркетинговый бюджет?

## Этапы
| Этап | Файл | Что делается |
|---|---|---|
| 1. Данные | `src/generate_data.py` | Выгрузки CRM: клиенты, заказы, товары за 2025 год (2000 клиентов, ~3300 заказов) с реальными ошибками: дубли, разные форматы дат, цены строкой, опечатки в городах, пропуски |
| 2. Очистка | `src/clean.py` | Нормализация, удаление дублей и мусора, объединение таблиц, лог качества данных |
| 3. Анализ | `src/analyze.py` | KPI (выручка, AOV, повторные покупки), динамика, категории, каналы, **когортное удержание**, **RFM-сегментация** |
| 4. Отчёт | `reports/report.md` | Выводы, графики и рекомендации |

## Запуск
```bash
pip install -r requirements.txt
python run_all.py
```
Результат: `reports/report.md`, `reports/figures/*.png`, `reports/rfm_segments.csv`.

## Как подставить реальные данные
Положите свои `customers.csv`, `orders.csv`, `products.csv` с теми же колонками в `data/raw/` и запустите только `python src/clean.py` и `python src/analyze.py`.
