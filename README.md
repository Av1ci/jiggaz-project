# DataStart — MVP курса по аналитике данных

Статическое веб-приложение без зависимостей: 7 модулей, тесты, прогресс и интерактивная практика на учебном датасете.

## Модули
1. Что такое аналитика данных
2. Типы данных и таблицы
3. Описательная статистика (считается на датасете)
4. Очистка данных
5. SQL: основы запросов
6. Визуализация данных
7. Практика: мини-исследование (конструктор отчёта + SQL + график)

## Запуск
Откройте `index.html` в браузере. Прогресс сохраняется в `localStorage`.

## Структура
- `index.html` — разметка
- `styles.css` — стили (светлая/тёмная тема, адаптив)
- `data.js` — датасет и контент модулей (добавляйте модули сюда)
- `app.js` — логика: навигация, тесты, статистика, конструктор
